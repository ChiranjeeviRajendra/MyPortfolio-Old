Frontend development

React
  • Build component-based interfaces with hooks, props, and state management.

Vue.js
  • Create reusable Vue components with reactive data, computed values, and event handling.
  • Build application views and integrate them with REST API services.

TypeScript & JavaScript
  • Use types, interfaces, and reusable functions to keep application code clear and maintainable.
  • Handle asynchronous operations with promises, async/await, and browser events.

HTML, CSS & Sass
  • Structure pages with semantic HTML and create responsive layouts for desktop and mobile screens.

Bootstrap
  • Build responsive layouts using Bootstrap's grid, utilities, and UI components.

RxJS
  • Compose observable streams for API responses, UI events, and asynchronous application flows.

Generative AI & workflows

  • Connect language models with relevant documents to ground responses in retrieved context.
  • Build retrieval pipelines covering document ingestion, chunking, embeddings, and context assembly.

LangChain
  • Connect prompts, language models, retrievers, and tools into reusable AI application flows.
  • Integrate retrieval and model interactions with backend services.

LangGraph
  • Build stateful AI workflows using graph-based steps and conditional transitions.
  • Coordinate model calls, tool use, and shared state across multi-step workflows.

Ollama & open-source models
  • Run open-source language models locally with Ollama for development and experimentation.
  • Connect locally hosted models to RAG pipelines and Python-based AI services.
